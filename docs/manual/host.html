本番：10月31日（土）・11月1日（日）2026年10月24日版

はじめに：司会がすることは「読む」と「次へを押す」だけ

スズリーグは、司会のスマホの「次へ」ボタンで進みます。 「次へ」を1回押すと、ステージの iPad・電子黒板・観客のスマホが、全部いっしょに次の場面へ切り替わります。 司会は台本を読み、区切りごとに「次へ」を押してください。

このほかに、ステージ袖に裏方のPCがあり、全部の画面をつないでいます。 裏方のPCはシステム担当（このシステムを作った開発担当）が動かすので、司会やイベント責任者が触る必要はありません。

このマニュアルの読み方

  • 1開演30分前に、4つの画面を開いておく当日の朝に読む
  • 2司会者画面の見方：大事なのは一番下の「次へ」リハーサルまでに読む
  • 3本番の進め方：1問は「次へ」4回で進むリハーサルまでに読む
  • 4出演者の答えが届かないときは、司会が代わりに入れるリハーサルまでに読む
  • 5観客ランキングで、変な名前を隠す必要なときに
  • 6困ったとき：症状から探す本番中に開く
  • 7付録：ページの一覧・ことば・連絡先必要なときに
写真の問題と数字は練習用です このマニュアルの画面写真は、練習用の例題で撮りました。本番の問題とは違います。 ステージの画面の問題文は、出演者に先に見えないように隠してあります。チーム名は本番のものです。

1開演30分前に、4つの画面を開いておく

本番が始まる前に、4つの画面を開いて「待っている状態」にしておきます。 裏方のPCが先に動いている必要があるので、システム担当から「動かしたよ」と言われてから始めてください。

スマホのカメラで下のQRコードを読み取ると、司会者画面が開きます。

音は「電子黒板」か「iPad」のどちらか片方だけ 両方から音が出ると、効果音が二重に聞こえます。使わないほうの音量を0にしてください。 iPad から音を出すときは、iPad の消音モード（マナーモード）を切ります。消音モードのままだと音が鳴りません。 iPad の自動ロックも「なし」にしておきます。

クラス委員に、印刷したQRコードを掲げてもらいます。観客がQRを読むと「観客ページ」が開き、 ニックネームを入れて参加します（1）。ログインは要りません。

  • 司会者画面の右上が緑の「PCと接続中」になっている

  • クラス委員がQRコードを持っている

2司会者画面の見方：大事なのは一番下の「次へ」

司会者画面は、上から「いまの状態」「いまの問題」「次へボタン」の順に並んでいます。 迷ったら「次へ」ボタンの下の小さい字を読んでください。押すと何が起きるかが書いてあります。

  1. つながっているか緑の「PCと接続中」なら大丈夫です。赤い字のときは6章へ。
  2. いまの進行「出題」「回答受付」「正解発表」など、いまの場面の名前です。
  3. 出演者の合言葉（4桁）iPad が壊れたときに使う予備の画面の合言葉です。ふだんは使いません（4章）。
  4. チーム名・何問目か・残りバルーンステージにいるチームの状態です。台本の「残りバルーンは◯個」はここを見て読みます。
  5. 問題文読み上げる問題と、アンケートの出典です。
  6. 正解を見る押している間だけ正解が出ます。指を離すと消えるので、周りから見られにくくなっています。

3本番の進め方：1問は「次へ」4回で進む

1チームは5問に答えます。1問ごとに「出題 → 回答受付 → 正解発表 → ラウンド結果」の4つの場面があり、 場面を変えるたびに「次へ」を1回押します。これを4チーム分くり返して、最後に表彰式です。

5観客ランキングで、変な名前を隠す

観客は、出演者と同じ問題にスマホで答えています。答えと正解の差が少ない人ほど上位になり、 表彰式のときに全員のスマホに上位の名前が出ます。名前は観客が自由に入れるので、ふさわしくない名前が混ざることがあります。

  1. 「観客ランキング」を開く画面を下にずらし、三角（▶）を押します。参加人数と、上位30人の名前が出ます。
  2. 「隠す」を押す押した名前は、全員のスマホのランキングに出なくなります。間違えたら「戻す」で元に戻せます。
  3. 「ランキングをリセット」は本番中に押さない観客の成績が全部消えて、元に戻せません。リハーサルのあとにシステム担当が使うボタンです。
観客の画面はこうなっている 観客ページでは、正解発表のたびに自分の予想と正解が出て、最後に順位がわかります。

6困ったとき：症状から探す

まず落ち着いてください。どの場面でも、進行の記録は裏方のPCに残っています。 画面がおかしくなっても、開き直せば今の場面に戻ります。上から順に試して、直らなければシステム担当を呼びます。

  • 答えが届く前に正解発表へは進めません（押せない作りです）。
  • 点数がおかしくなったなど、困ったことになったらシステム担当を呼びます。
音が出ない・二重に聞こえる
  • 出ない：画面を1回クリック（タップ）したか、音量と消音モードを確かめます。
  • 二重：電子黒板と iPad の両方から出ています。片方の音量を0にします。
観客から「画面が進まない」と言われた

観客ページを再読み込みしてもらいます。途中からでも今の場面に追いつきます。

司会のスマホが使えなくなった（電池切れ・落とした）

別のスマホで司会者画面を開き、合言葉を入れれば同じように操作できます。間に合わないときは、裏方のPCにも同じ司会者画面が開いているので、システム担当に「次へ」を押してもらいます。
