イベント責任者・司会のみなさんへ
当日、スマホの「司会者画面」で進行を動かすための説明書です
本番：11月1日（日）10時開始2026年10月25日版

はじめに：司会がふだんすることは、台本を読んで「次へ」を押すことだけ

スズリーグは、司会のスマホの「次へ」ボタンで進みます。 「次へ」を1回押すと、ステージの iPad・電子黒板・観客のスマホが、全部いっしょに次の場面へ切り替わります。 司会は台本を読み、区切りごとに「次へ」を押してください。

このマニュアルの読み方

  • 1開演30分前に、4つの画面を開いておくリハーサルまでに読む
  • 2司会者画面の見方：大事なのは一番下の「次へ」リハーサルまでに読む
  • 3本番の進め方：1問は「次へ」4回で進むリハーサルまでに読む
  • 4出演者の答えが届かないときは、司会が代わりに入れるリハーサルまでに読む
  • 5観客ランキングでは変な名前を隠せる。リセットは押さない必要なときに
  • 6困ったとき：画面に出た言葉や症状から探す本番中に開く
  • 7付録：ページの一覧・ことば・連絡先必要なときに

1〜4章は、リハーサルまでに一度通して読んでおいてください。当日の朝は1章をもう一度見ながら準備します。本番中に困ったら6章を開きます。

写真の問題と数字は練習用です このマニュアルの画面写真は、練習用の例題で撮りました。本番の問題とは違います。 写真に写っているステージの画面は、問題文を塗りつぶしてあります。出演者に先に見えないようにするためです。チーム名は本番のものです。

1開演30分前に、4つの画面を開いておく

本番が始まる前に、4つの画面を開いて「待っている状態」にしておきます。 裏方のPCが先に動いている必要があるので、システム担当から「動かしたよ」と言われてから始めてください。

リハーサルでは、1チーム分を通しておく この章の準備をして、1チーム分（5問）を本番どおりに進めてみます。「正解を見る」と代理入力（4章）も一度ずつ試し、音をどちらの機械から出すかを音響と決めておきます。 リハーサルのあと、システム担当が成績を消して合言葉を変えることがあります。そのときは、司会のスマホで新しい合言葉を入れ直してください。

スマホのカメラで下のQRコードを読み取ると、司会者画面が開きます。

1-3　ステージの iPad（出演者の画面）を開く

出演者が答えるための iPad です。Safari で次のアドレスを開き、画面を1回タップします。電子黒板と同じ「開始までしばらくお待ちください…」が出れば準備完了です。

https://suzuleague-cloud.onrender.com/stage/play/

出演者が立つ位置から押しやすい向きに置きます。答え方は、出演者マニュアルの3章にも載っています。

音は「電子黒板」か「iPad」のどちらか片方だけ 両方から音が出ると、効果音が二重に聞こえます。使わないほうの音量を0にしてください。 iPad から音を出すときは、iPad の消音モード（マナーモード）を切ります。消音モードのままだと音が鳴りません。 iPad の自動ロックも「なし」にして、充電しておきます。

1-4　観客にQRコードを読んでもらう

クラス委員に、印刷したQRコードを掲げてもらいます。観客がQRを読むと「観客ページ」が開き、 ニックネームを入れて参加します（1）。ログインは要りません。名前を出したくない人は「名前を出さずに参加する」を押せば参加できます。

  • 音は片方からだけ出る（iPad から出すなら、消音モードを切ってある）

2司会者画面の見方：大事なのは一番下の「次へ」

司会者画面は、上から「いまの状態」「いまの問題」「次へボタン」の順に並んでいます。 迷ったら「次へ」ボタンの下の小さい字を読んでください。押すと何が起きるかが書いてあります。

  1. つながっているか緑の「PCと接続中」なら問題ありません。赤い字のときは6章へ。
  2. いまの進行「出題」「回答受付」「正解発表」など、いまの場面の名前です。
  3. 出演者の合言葉（4桁）iPad が動かないときに使う、予備の回答画面の合言葉です。ふだんは使いません（4章）。
  4. チーム名・何問目か・残りバルーンステージにいるチームの状態です。台本の「残りバルーンは◯個」はここを見て読みます。
  5. 問題文読み上げる問題と、アンケートの出典です。
  6. 正解を見る押している間だけ正解が出ます。指を離すと消えるので、周りから見られにくくなっています。
  7. 次へ押すと、全部の画面が次の場面に進みます。下の小さい字は「押すと何が起きるか」です（この写真なら「回答受付を始める」）。

「次へ」が押せないときは、理由が小さい字で出る

「次へ」が薄い色になって押せないときがあります。故障ではありません。小さい字に理由が出ているので、下の例のように待つか、書いてあるとおりに対応してください。

押している間だけ正解が見える

「正解を見る」を指で押さえている間だけ、正解が出ます（1）。指を離すと元に戻ります。

正解の読み上げは、大画面で正解が出てからにしてください。観客のスマホにも、大画面の演出が終わってから正解が出ます。

下のほうにある3つの欄は、ふだんは閉じたままでよい

画面を下にずらすと「全チームの状況」「観客ランキング」「困ったとき」の3つの欄があります。三角（▶）を押すと開きます。

全チームの状況4チームの残りバルーン・何問終わったか・クリアしたかの一覧。表彰式の前の確認に使えます（3章の最後）。
観客ランキング観客の順位。変なニックネームを隠せます（5章）。

3本番の進め方：1問は「次へ」4回で進む

各チームはバルーン100個で始まり、答えと正解の差の数だけバルーンが割れます（くわしくは出演者マニュアルの1章）。 1チームは5問に答えます。1問ごとに「出題 → 回答受付 → 正解発表 → 1問ごとの結果（ラウンド結果）」の4つの場面があり、 場面を変えるたびに「次へ」を1回押します。5問が終わると次のチームに替わり、4チームが終わったら表彰式です。 チームはチーム1から順に登場します（チーム1 みみみンズwithoutみみみ → チーム2 チーム煩悩 → チーム3 スシタベタイ → チーム4 寮生）。

場面司会がすること「次へ」を押す合図押すと

チーム紹介登場インタビュー「それではゲームを始めます！」1問目が出る

回答受付シンキングタイム（20秒）・「それでは答えをどうぞ！」タイマーの音楽が終わり、「それでは答えをどうぞ！」と言ったあと（答えが届いていれば押せる）正解発表に進む

全体結果表彰式（これで終わり。もう押せない）

4チーム目のチーム結果のあとは、全チームがステージにそろい、「今から表彰式を行います」と言うときに押すと全体結果が出ます。

「次へ」は1回ずつ、ゆっくり押す 1秒以内に2回押すと、2回目は取り消されます（押しすぎて場面が飛ばないようにするため）。 1回押したら、画面の「いまの進行」が変わったのを見てから次に進んでください。 前の場面に戻すボタンはありません。早く進めてしまったときは、そのまま台本を続けます（6章）。
司会がその場で決めることが2つある
  • 誰が答えるか：1問ごとに司会が指名します。システムは答えた人を記録しません。人数が少ないチームは、1人が2問以上答えます。チームで答える順番を決めてあれば、それに合わせて指名します。
  • シンキングタイムの20秒：システムでは計りません。音響が流すタイマーの音楽が終わったら、「それでは答えをどうぞ！」と声をかけます。

4出演者の答えが届かないときは、司会が代わりに入れる

iPad の調子が悪い、押し方がわからない、などで答えが届かないときは、 出演者に答えを口で言ってもらい、司会者画面に司会が入力します。これを代理入力と呼びます。

代理入力：「出演者の回答」の欄に数字を入れて「代理入力」を押す

押すと
iPad
では
  1. 数字を入れる「回答受付」の場面で、「出演者の回答」の欄に 0〜100 の数字を入れます。この欄は回答受付の間だけ出ます。小数や101以上を入れると「0〜100の整数を入力してください」と出て、送られません。
  2. 「代理入力」を押す欄の下に「出演者のスマホから届かないときだけ使う」と書いてありますが、iPad から届かないときも同じように使えます。
  3. 「届いた回答」に数字が出る出演者が iPad で答えたときと同じ扱いになり、「次へ」が押せるようになります。
  4. iPad と大画面にもその数字が出る数字のボタンは引っ込みます。
出演者がすでに iPad で答えていても、代理入力をすると、iPad で送った答えが代理入力で入れた数字に置きかわります。出演者が押し間違えたまま GO を押したときも、正解発表の前ならこれで直せます。

5観客ランキングでは変な名前を隠せる。リセットは押さない

観客は、出演者と同じ問題にスマホで答えています。20問の「答えと正解の差」を足した数が少ない人ほど上位です。答えなかった問題は、差50として数えます。 表彰式のときに、全員のスマホに上位5人の名前が出ます。名前は観客が自由に入れるので、ふさわしくない名前が混ざることがあります。

「ランキングをリセット」は本番中に押さない 押すと、観客の成績が全部消えて、元に戻せません。リハーサルのあとにシステム担当が使うボタンです。 間違えて押したときは確認が出るので、「キャンセル」を押してください。
  1. 「観客ランキング」を開く画面を下にずらし、三角（▶）を押します。参加人数と、上位30人の名前が出ます。
  2. 「隠す」を押す押した名前は、全員のスマホのランキングに出なくなります。間違えたら「戻す」で元に戻せます。
  3. 「ランキングをリセット」本番中は押しません（上の囲み）。
観客の画面はこうなっている 観客ページでは、正解発表のたびに自分の予想と正解が出て、最後に順位がわかります。

6困ったとき：画面に出た言葉や症状から探す

まず落ち着いてください。どの場面でも、進行の記録は裏方のPCに残っています。 画面がおかしくなっても、開き直せば今の場面に戻ります。困ったことに近い見出しを探し、その中の手順を上から順に試します。直らなければシステム担当を呼びます。

司会者画面に赤い字で「PCの応答なし」と出て、「次へ」が押せない

裏方のPCが止まっています。司会者画面からは直せません。

  1. すぐにシステム担当を呼ぶ。システム担当が裏方のPCを動かし直せば、数分で止まる前の問題・バルーンのまま再開できます。
  2. 待っている間は「次へ」を連打しない。押せないようになっているので、押しても何も起きません。
  3. 右上が緑の「PCと接続中」に戻ったら、そのまま続けます。

「PCがまだつながっていません」と出るときも同じです（開演前なら、裏方のPCがまだ動いていません）。

司会者画面に赤い字で「サーバにつながりません」と出る

司会のスマホが、インターネット上の中継役のコンピュータ（サーバ）につながっていません。全部の画面は、このサーバを通して裏方のPCとやり取りしています。スマホの電波が原因のことが多く、そのときは進行は止まっていません。

  1. スマホの電波や Wi-Fi を確かめます。Wi-Fi が弱い場所なら、Wi-Fi を切ってモバイル回線にすると直ることがあります。
  2. 直らなければ、ほかの人のスマホで司会者画面を開いて続けます（下の「司会のスマホが使えなくなった」）。
  3. 大画面や観客のスマホも止まっているときは、サーバそのものが止まっています。システム担当を呼びます。
大画面や iPad の表示がおかしい・止まった・ずれている
  1. まず、開いたまま直せるか試します。司会者画面の「困ったとき」を開いて「Scratch に今の状態を送り直す」を押します（1）。Scratch は、大画面と iPad の画面を動かしているソフトの名前です。下に「Scratch に今の状態を送り直しました」と出ます（2）。
  2. それで直らなければ、画面の係が、おかしいほうの画面を再読み込みします（PC は F5 キー、iPad はアドレスの横の ↻）。そのあと画面を1回クリック（iPad はタップ）すると、今の場面の画面に戻ります。
  3. それでもだめなら、出演者の答えは代理入力（4章）で入れて進めます。大画面がなくても、司会者画面と観客ページで進行は続けられます。
出演者の答えが司会者画面に届かない（ずっと「回答を待っています」）
  1. 出演者が最後に GO を押したか確かめます。数字を押しただけでは届きません。
  2. 届かなければ、答えを口で言ってもらい、代理入力で入れます（4章）。
「次へ」を押したら、下に赤い字が出て進まない

合言葉はリハーサルのあとに変えることがあります。本番の前に、司会のスマホで一度開いて確かめておくと安心です。

間違えて「次へ」を押して、場面が先に進んでしまった

前の場面に戻すボタンはありません。進んだ場面に合わせて、台本を続けてください。

  • 問題を読む前に「回答受付」に進んだ → そのまま問題を読み、シンキングタイムにします。
  • インタビューの途中で次のチームの紹介に進んだ → 大画面に次のチーム名が出ますが、インタビューを終えてから次のチームを呼べば問題ありません。
  • 答えが届く前に正解発表へは進めません（押せない作りです）。
  • 点数がおかしくなったなど、困ったことになったらシステム担当を呼びます。
音が出ない・二重に聞こえる
  • 出ない：音を出すほうの機械（電子黒板のPC か iPad）の画面を1回クリック（タップ）したか、音量と消音モードを確かめます。
  • 二重：電子黒板と iPad の両方から出ています。片方の音量を0にします。
観客から「画面が進まない」と言われた

観客ページを開き直してもらいます（ブラウザの ↻ を押すか、QRコードを読み直す）。途中からでも今の場面に追いつきます。

司会のスマホが使えなくなった（電池切れ・落とした）

別のスマホで司会者画面を開き、合言葉を入れれば同じように操作できます。間に合わないときは、裏方のPCにも同じ司会者画面が開いているので、システム担当に「次へ」を押してもらいます。

チームが時間になっても来ない

ステージ裏の誘導係に呼びに行ってもらい、その間はトークでつなぎます。システムは4チームがチーム1から順に出る前提で動いていて、順番を入れかえたりチームを抜かしたりはできません。どうしても来られないときは、システム担当に相談します。
