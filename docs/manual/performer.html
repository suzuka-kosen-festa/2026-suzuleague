はじめに：答えるときに押すのは「数字」と「GO」だけ

スズリーグは、アンケートの結果が何パーセントだったかを当てるクイズです。 ステージには iPad が1台置いてあり、答える人は数字を押して、最後に「GO」を押します。 それ以外の操作は、司会と係の人がやります。

  • 1ルール：100個のバルーンを、5問でなるべく残す
  • 2ステージでの流れ：登場してから戻るまで
  • 3iPad で答える：数字を押して GO
  • 4チームの結果と、バルーンがなくなったとき
  • 5iPad が動かないときは、スマホで答える
  • 6困ったとき
写真の問題と数字は練習用です このマニュアルの写真は練習用の例題で撮りました。本番の問題は当日のお楽しみなので、 写真の問題文は隠してあります。チーム名は本番のものです。

1ルール：100個のバルーンを、5問でなるべく残す

チームはバルーン100個を持ってスタートします。 問題は「◯◯な人は何パーセント？」という形で、0〜100の数字で答えます。 答えと正解がずれた分だけ、バルーンが割れて減っていきます。

割れるバルーンの数 ＝ 答えと正解の差
例：答えが 62%、正解が 64% なら、差は 2。バルーンが 2個 割れて、残りは 98個
  1. 予想チームが答えた数字
  2. 正解アンケートの本当の結果
  3. 誤差2つの差。この数だけバルーンが割れる
  4. 残りチームに残っているバルーンの数

ぴったり当てれば、バルーンは1個も割れません。

問題の数1チーム5問。チームの中で誰が何問目に答えるかは、司会がその場で指名します。人数が少ないチームは、1人が2問以上答えることがあります。
クリア5問が終わったとき、バルーンが1個でも残っていればクリアです。
ゲームオーバー途中でバルーンが0個になると、ゲームオーバーです。残りの問題は「エキシビション」（点数に関係ない、おまけの問題）として答えます（4章）。
優勝クリアしたチームの中で、バルーンが一番多く残ったチームが優勝です。景品はお菓子の詰め合わせ。同じ数なら、そのチーム全部が優勝です。
観客のみなさんも、自分のスマホで同じ問題に答えています。観客に負けないようにがんばってください。

2ステージでの流れ：登場してから戻るまで

1チームがステージにいるのは8分ほどです。呼ばれるまではステージ裏で待ちます。

順番することiPad の画面
① 登場司会に呼ばれたらステージへ。代表の人が、チーム名の由来と意気込みを話します。チーム名が出る
② 問題司会が問題を読みます。答える人を司会が指名します。問題が出る
③ 答えるシンキングタイム（20秒）の間に、iPad で数字を押して GO（3章）。チームで相談しても大丈夫です。数字のボタンが出る
④ 正解発表司会が「回答者の答えは◯◯%です！正解は…」と言い、正解が出ます。ゲージが動いて正解が出る
⑤ くり返し②〜④を5問くり返します。
⑥ 結果クリアか失敗かが出ます。そのあと感想インタビュー。終わったらステージ裏へ戻ります。チームの結果が出る
⑦ 表彰式4チームが終わったら、全チームでもう一度ステージへ。優勝チームの発表です。全体の結果が出る
画面は司会の進行に合わせて自動で切り替わります。答えるとき以外は、iPad に触らなくて大丈夫です。

3iPad で答える：数字を押して GO

司会が「ではお考えください」と言うと、画面の下に数字のボタンが出ます。答えは次の3ステップで送ります。

ステップ 1

数字のボタンが出るのを待つ

  1. 数字のボタン（1〜9、0）答えの数字を押します。
  2. GO（赤い丸）答えを送るボタン。最後に押します。
  3. Delete（青い丸）押した数字を消します。押し間違えたときに使います。
  4. 予想押した数字がここに出ます。
ステップ 2

数字を押して、「予想」の数字を確かめる

たとえば 62% と答えるなら、6 → 2 の順に押します。

  1. 「予想」に押した数字が出る思っている数字と同じか、必ず確かめてください。
  • 100% のときは 1 0 0、5% のときは 5 だけ押します。
  • 間違えたら Delete で消して、押し直します。
  • 画面は指で軽くトンと押します。強く長く押す必要はありません。
ステップ 3

「GO」を押すと答えが送られる

赤い GO を押すと、答えが司会に届きます。数字のボタンが引っ込めば成功です（1 の数字が残ります）。

GO のあとは直せません GO を押すと数字のボタンが消えるので、iPad では直せなくなります。 どうしても直したいときは、すぐに司会に伝えてください。司会が直せます。

大画面（電子黒板）にも、チームの予想の数字が出ます。

4チームの結果と、バルーンがなくなったとき

5問終わってバルーンが残っていれば「クリア」

結果が出たら、司会が感想を聞きます。インタビューが終わったらステージ裏に戻ってください。

途中でバルーンが0になったら、残りは「エキシビション」

ゲームオーバーになっても、ステージから下りずに残りの問題に答えます。 エキシビションの問題は点数に関係しないので、気楽に答えてください。答え方（数字を押して GO）は同じです。

表彰式：4チームの結果がそろって出る

4チーム全部が終わると、全チームがステージに上がり、チームごとの残りバルーンと順位が出ます。

優勝チームには、イベント代表者から景品（お菓子の詰め合わせ）が渡されます。優勝インタビューもあるので、ひとこと考えておいてください。

5iPad が動かないときは、スマホで答える

iPad が固まったときは、司会が答えを代わりに入れてくれます（答えを口で伝えてください）。 司会に「スマホで答えて」と言われたときだけ、自分のスマホで予備の回答画面を開きます。

6困ったとき

困ったら、まず司会に声をかけてください。司会の手元のスマホで、たいていのことは直せます。

数字のボタンが出てこない

司会が「ではお考えください」と言ったあとに出ます。それでも出なければ、答えの数字を司会に口で伝えてください。司会が代わりに入れます。

押し間違えたまま GO を押してしまった

すぐに司会に、本当の答えを伝えてください。正解発表の前なら、司会が直せます。

ボタンを押しても反応しない・画面が止まった

指で軽くトンと押し直してみます。それでもだめなら、自分で直そうとせずに司会か係の人に伝えてください。係の人が画面を開き直します。

チームで答えが決まらない

シンキングタイムは20秒です。迷ったら、指名された人が決めて GO を押してください。

iPad のここは触らないでください
  • 画面の右上の四角いボタン（全画面の切り替え）
  • Safari のアドレスや「戻る」「↻（再読み込み）」
  • iPad の横や上のボタン（画面が消えたり、音が変わったりします）
楽しんでください！ 観客もスマホで一緒に答えています。
