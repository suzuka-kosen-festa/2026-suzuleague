# Scratch担当に渡すもの

## ステージ画面は、プロジェクトから作り直して配っている（2026-10-13〜）

本番で開くのは、プロジェクト `1364239598` そのものではなく、そこから作り直した2つの画面。
大画面に映す**入力なし**の画面と、出演者が答える**入力あり**の画面で、どちらも Render から配る。

- 大画面用: <https://suzuleague-cloud.onrender.com/stage/view/>
- 出演者用: <https://suzuleague-cloud.onrender.com/stage/play/>

絵・音・演出はプロジェクトのものをそのまま使う。入れ替えたのは、裏方PCとやり取りするスプライト「通信」のスクリプトだけ。
途中で開き直すと崩れる件（[#52](https://github.com/suzuka-kosen-festa/2026-suzuleague/issues/52)）と、各チームの1問目でテンキーが出ない件（[#53](https://github.com/suzuka-kosen-festa/2026-suzuleague/issues/53)）は、この画面で解消したので **Scratch 側で直さなくてよい**。

Scratch担当にお願いしたいのは次の3つ（[#56](https://github.com/suzuka-kosen-festa/2026-suzuleague/issues/56)）。

1. **プロジェクトを直したら知らせる。** 作り直すまで本番の画面には出ない（開発側がコマンド1つで作り直す）
2. **メッセージと変数の名前を変えるときは、変える前に知らせる。** 「通信」は `初期化`・`4_正解発表`・`途中復帰_出題UI同期` などのメッセージと、`回答中`・`風船の数`・`予想%` などの変数を名前で使っている。一覧は [protocol.md](../protocol.md#元のプロジェクトに頼っていることscratch担当へ)
3. **全体結果（ステート8）の得点表を仕上げる。** 今はリスト `得点表` のモニターが「チーム1」の見出しに重なり、マスは空のまま。大画面に映るので、表彰式で見せられる形にしてほしい。全チームの残りバルーンは、「通信」がリスト `得点表` にチーム番号順で入れてから `8_終了` を送る（チームは4つ）

### 作り直しのときに見つけて、開発側で補ったこと

プロジェクト側でも直しておくと、TurboWarp で直接開いたときも同じになる。

- **問題番号が1つ前にずれる**: 「コスチュームを（`☁ P2S_ROUND`）にする」は、値が数値で届くとコスチュームの番号で選ばれる（3問目なのに「2」が光る）。裏方PCが値を文字列で送るようにして解消した
- **2チーム目から、チーム名の札が出ない**: `初期化` の直後に `1_チーム紹介` を送っているので、札のクローンができる前にメッセージが通り過ぎる。作り直した画面では、少し待ってから送っている
- **途中から画面を組み立てるとき、問題文の絵が切り替わらない**: スプライト「問題」の `途中復帰_出題UI同期` の受け手に、コスチュームの切り替えがない
- **`途中復帰_背景同期` は、背景がすでに合っているとゲームオーバーの背景にする**: 各条件に「背景が◯番でない」が入っているので、合っているときは最後の「でなければ」に落ちる
- **5問目でゲームオーバーになると、GAME OVER の文字が次のチームにも残る**: 文字を隠すのは「次の問題へ」のときだけで、チームが替わるときに消す処理がない（次のチームのタイトルに重なる）

## 問題を差し替えるとき

問題文は、スプライト「問題」の**コスチューム（画像）**で出している。名前は「チーム番号-何問目」（`1-1`〜`4-5`）で、
`☁ P2S_TEAM` と `☁ P2S_ROUND` から切り替える。リスト `問題文` は使われていない。

文言の元は `問題文リスト.txt`（1行1問・20行。行番号 = 問題ID で、チーム1が1〜5行目、チーム2が6〜10行目…）。
開発側が問題を差し替えたら、このファイルを作り直して渡す。

```bash
uv run python -m suzuleague.questions > "docs/scratch/問題文リスト.txt"
```

画像を差し替えたら知らせてほしい。開発側が20枚を問題表と照合してから、ステージ画面を作り直す。

## 手元で試すとき

元のプロジェクトを TurboWarp で開けば、これまでどおり裏方PCとつながる。
`https://turbowarp.org/1364239598?cloud_host=wss://suzuleague-cloud.onrender.com`（`?cloud_host=` を落とすと無言でつながらない）

- 裏方PCからの値は**文字列**で届く（`"3"`）。エディタで変数に値を入れて試したときと同じ動きになる
- `☁ P2S_*` には書き込まない（同じルームに大画面・出演者の端末・観客のスマホがいる）
- 通信の決まりは [protocol.md](../protocol.md)
