前日まで裏方

  • 裏方司会者画面の合言葉を作り直した（Render の HOST_TOKEN。アプリで入れ直す）
  • 裏方teams.json を作り、ステージ画面を作り直した（札とカードにチーム名）
  • 裏方画面が最新: publish --check・stage --check がどちらも ✓
  • 裏方リハーサル後、スマホの司会者画面で「ランキングをリセット」を押した
  • 裏方QRコードを印刷した（docs/qr/print.html）
  • 司会司会のスマホで司会者画面を開き、新しい合言葉を入れた

開演30分前全員

  • 裏方ブラウザで suzuleague-cloud.onrender.com を開いてサーバを起こす（寝ていると約20秒）
  • 裏方裏方PCのスリープを切り、電源につなぐ
  • 裏方スズリーグ.app で「本番」→ 「最初から」を選ぶ（リハーサルの続きで始めない）
  • 司会司会者画面が「PCと接続中」になっている
  • 大画面/stage/view/ を開いて1回クリック → 右上で全画面
  • 出演者/stage/play/ を開いて1回クリック
  • 両方「開始までお待ちください」が出ている。スリープ・自動ロックを切った
  • 両方音は片方だけ（もう片方は消音）

司会へひとこと開演前に

  • 「次へ」は続けて押さない（1秒以内の2回目は取り消される）
  • 正解発表のあと15秒は「次へ」が押せない（大画面の演出待ち。残り秒数が出る）
  • 出演者の回答が届かないときは、司会者画面の「代理入力」で入れる
  • ステージの端末が動かないときだけ、予備の回答画面と4桁の合言葉を出演者に伝える
  • 同点で優勝が複数のこともある（画面に「同点優勝」と出る）

困ったとき慌てず上から

大画面・出演者の画面がおかしい再読み込みして1回クリック。または司会者画面「困ったとき」→「Scratch に今の状態を送り直す」
司会者画面が「PCの応答なし」裏方PCで スズリーグ.app を開き直し、「続きから」
