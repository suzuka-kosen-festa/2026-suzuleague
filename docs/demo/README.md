# 10/7 デモの段取り

前回のデモ会で「足りない」と言われた5つ（視聴者参加画面・スマホ用UI・ランキング・リザルト・司会者画面）を、
**全員が自分のスマホで見る**形で一通り見せる。所要時間は準備10分・本編10分ほど。

本番は4チーム×5問だが、デモでは**1チーム5問**で全体結果（リザルト・ランキング）まで行く。
チーム構成は `docs/demo/teams-demo.json`（「デモチーム」1チームだけ）を使う。

## 用意するもの

| 役 | 端末 | 開く画面 |
|---|---|---|
| 裏方 | PC 1台 | ダッシュボード（ターミナル） |
| 司会役 | スマホ 1台 | 司会者画面 <https://suzuleague-cloud.onrender.com/host.html> |
| 出演者役 | スマホ 1台 | 回答画面 <https://suzuleague-cloud.onrender.com/player.html>（QR: `docs/qr/player.png`） |
| 観客役 | デモ会の参加者のスマホ | 観客ページ <https://suzuleague-cloud.onrender.com/suzuleague.html>（QR: `docs/qr/audience.png`） |

QRは `docs/qr/print.html` を印刷するか、PCの画面に `docs/qr/audience.png` を出して読み取ってもらう。

## 準備（開始10分前）

1. **Render を起こす**。ブラウザで <https://suzuleague-cloud.onrender.com> を開く（寝ていると起動に数十秒かかる）
2. **本番の画面が最新か確かめる**
   ```bash
   cd ~/repository/snctfes2026-suzuleague
   uv run python -m suzuleague.publish --room-id 1364239598 --check
   ```
3. **ダッシュボードを起動する**（デモ用のルームと1チーム構成を使う。本番のScratchのルームは使わない）
   ```bash
   export SUZULEAGUE_HOST_TOKEN='（Render の HOST_TOKEN と同じ合言葉）'
   uv run suzuleague --cloud-host wss://suzuleague-cloud.onrender.com \
     --project-id 1364239598 --teams docs/demo/teams-demo.json --web
   ```
   - 観客ページは本番ルーム `1364239598` につながる作りなので、デモでも同じルームを使う
   - Scratch のステージ画面は使わない（#41 で扱いを相談中）
4. 司会役のスマホで司会者画面を開き、合言葉を入れる。「PCと接続中」になればよい
5. 司会者画面の「観客ランキング」を開き、**「ランキングをリセット」**を押す（前の試験のデータを消す）
6. 観客役の参加者にQRを読み取ってもらい、ニックネームを入れてもらう

## 本編

| 段階 | 司会者画面で押すボタン | 見せるところ |
|---|---|---|
| チーム登場 | 次へ（1チーム目を登場させる） | 司会者画面に**出演者の合言葉（4桁）**が出る。出演者役が回答画面に入力する |
| 出題 | 次へ（1問目を出題する） | 全員のスマホに問題文が出る |
| 回答受付 | 次へ（回答受付を始める） | 出演者役は数字キーで、観客はスライダーで回答する。司会者画面に届いた回答が出る |
| 正解発表 | 次へ（正解を発表する） | 回答画面・観客ページに正解と割れた数。観客ページには**ステージの回答**も出る |
| ラウンド結果 → 2問目… | 次へ | 5問目まで繰り返す（2〜4問目は手早く） |
| チーム結果 | 次へ（チーム結果を出す） | 観客ページに**自分の観客ランキングの順位** |
| 全体結果 | 次へ（全体結果を出す） | 全員のスマホに**優勝チーム・景品の案内・チームの順位・観客ランキング上位** |

途中で見せておきたいもの:

- 司会者画面の「正解を見る」は**押している間だけ**正解が出る
- 回答画面に違う合言葉を入れると弾かれる（観客のなりすまし対策）
- 司会者画面の「観客ランキング」から、不適切な名前を**隠せる**

## 困ったとき

| 症状 | 対処 |
|---|---|
| 司会者画面が「PCの応答なし」 | ダッシュボードが動いているか確認。急ぐときは裏方PCで <http://localhost:8000/host> を開いて操作する |
| 回答画面で「合言葉が違います」 | 司会者画面に出ている4桁を入れ直す（チームが変わると合言葉も変わる） |
| 出演者の回答が届かない | 司会者画面の「代理入力」で数字を入れる |
| 観客ページが進まない | ページを再読み込みする（途中からでも追いつく） |
| 「次へ」が押せない | 回答受付中は回答が届くまで押せない。代理入力で入れる |

## 終わったら

- ダッシュボードを `quit` で終了する
- 司会者画面の「ランキングをリセット」でデモのデータを消す
