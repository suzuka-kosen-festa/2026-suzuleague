# デモ・リハーサルの段取り

司会・出演者・観客・大画面の画面を、少人数で一通り動かすときの手順。所要時間は準備10分・本編10分ほど。
10/7 と 10/13 のデモ会はこの段取りで行った（10/13 の指摘で、大画面用のステージ画面が加わった）。

本番は4チーム×5問だが、デモでは**1チーム5問**で全体結果（リザルト・ランキング）まで行く。
チーム構成は `docs/demo/teams-demo.json`（「デモチーム」1チームだけ）を使う。

## 用意するもの

| 役 | 端末 | 開く画面 |
|---|---|---|
| 裏方 | PC 1台 | `launcher/スズリーグ.app` |
| 司会役 | スマホ 1台 | 司会者画面 <https://suzuleague-cloud.onrender.com/host.html> |
| 出演者役 | PCかタブレット 1台 | **ステージ画面（出演者用）** <https://suzuleague-cloud.onrender.com/stage/play/> |
| 大画面 | PC 1台＋プロジェクターかモニター | **ステージ画面（大画面用・入力なし）** <https://suzuleague-cloud.onrender.com/stage/view/>。裏方PCと兼ねてもよい |
| （予備） | スマホ | ステージの端末が動かないときの回答画面 <https://suzuleague-cloud.onrender.com/player.html>（QR: `docs/qr/player.png`） |
| 観客役 | デモ会の参加者のスマホ | 観客ページ <https://suzuleague-cloud.onrender.com/suzuleague.html>（QR: `docs/qr/audience.png`） |

QRは `docs/qr/print.html` を印刷するか、PCの画面に `docs/qr/audience.png` を出して読み取ってもらう。

## 準備（開始10分前）

1. **裏方PCで `launcher/スズリーグ.app` を開き、「デモ（1チーム5問）」を選ぶ**。ターミナルは開かない。次を順に自動で行う
   - Render を起こし、合言葉が Render と一致するか確かめる（寝ていると起動に数十秒かかる）
   - 本番の画面が最新か確かめる（`publish --check`）
   - 本番のルーム `1364239598` とデモ用の1チーム構成でダッシュボードを裏で起動する
   - 裏方PCのブラウザで司会者画面（予備）を開く

   初回だけ合言葉（Render の `HOST_TOKEN` と同じもの）を聞かれる。`launcher/settings.env` に保存され、Git には入らない。
   コマンドも打てるターミナル版は `launcher/デモを起動.command`。中身は次と同じ。
   ```bash
   export SUZULEAGUE_HOST_TOKEN='（Render の HOST_TOKEN と同じ合言葉）'
   uv run suzuleague --cloud-host wss://suzuleague-cloud.onrender.com \
     --project-id 1364239598 --teams docs/demo/teams-demo.json --web
   ```
2. 司会役のスマホで司会者画面を開き、合言葉を入れる。「PCと接続中」になればよい
3. 出演者役の端末でステージ画面（出演者用）を、大画面のPCでステージ画面（大画面用）を開き、**それぞれ画面を1回クリックする**（クリックするまで音が出ない）。「開始までお待ちください」になればよい。大画面用は右上のボタンで全画面にする。**音は片方だけ出す**（両方から出ると二重になる）
4. **スマホの**司会者画面の「観客ランキング」を開き、**「ランキングをリセット」**を押す（前の試験のデータを消す。PCの司会者画面にはこのボタンがない）
5. 観客役の参加者にQRを読み取ってもらい、ニックネームを入れてもらう

> ステージ画面は、途中で再読み込みしても1回クリックすれば今の画面に戻る。
> 正解発表のあとは、**大画面に正解が出てから**「次へ」を押す（約13秒。早いと演出が切れる）。

## 本編

| 段階 | 司会者画面で押すボタン | 見せるところ |
|---|---|---|
| チーム登場 | 次へ（1チーム目を登場させる） | ステージ画面と観客ページにチームが出る |
| 出題 | 次へ（1問目を出題する） | 全員のスマホに問題文が出る |
| 回答受付 | 次へ（回答受付を始める） | 出演者役はステージ画面の数字キーで、観客はスライダーで回答する。司会者画面に**届いた回答**が出て、**大画面にも出演者の予想**が出る |
| 正解発表 | 次へ（正解を発表する） | ステージ画面でゲージが動き、約13秒後に正解が出てバルーンが割れる。観客ページは、そのあと（15秒後）に正解・割れた数・**ステージの回答**を出す |
| ラウンド結果 → 2問目… | 次へ | 5問目まで繰り返す（2〜4問目は手早く） |
| チーム結果 | 次へ（チーム結果を出す） | 観客ページに**自分の観客ランキングの順位** |
| 全体結果 | 次へ（全体結果を出す） | 観客ページと司会者画面に**優勝チーム・景品の案内・チームの順位・観客ランキング上位**。ステージ画面にはチームごとの残りバルーン・順位・優勝 |

途中で見せておきたいもの:

- 司会者画面の「正解を見る」は**押している間だけ**正解が出る
- （予備の回答画面を見せる場合）司会者画面に出る**4桁の合言葉**がないと答えられない（観客のなりすまし対策）
- 司会者画面の「観客ランキング」から、不適切な名前を**隠せる**

## 困ったとき

| 症状 | 対処 |
|---|---|
| 司会者画面が「PCの応答なし」 | 裏方PCが動いているか確認。止まっていたら `スズリーグ.app` を開き直し、**「続きから」**を選ぶ（落ちる前の問題・バルーンから再開できる） |
| ステージ画面が進まない・おかしい | 再読み込みして1回クリックする（今の画面に戻る）。開いたまま直すなら、司会者画面の「困ったとき」→「Scratch に今の状態を送り直す」。それでもだめなら、残りの問題は予備の回答画面で答えてもらう |
| ステージ画面の音が出ない | 画面を1回クリックしたか確認する。端末の音量と消音も見る |
| 「ランキングをリセット」が見当たらない | PCの司会者画面（`localhost`）ではランキングを操作できない。スマホの司会者画面で行う |
| 出演者の回答が届かない | 司会者画面の「代理入力」で数字を入れる（ステージ画面にもその数字が出る）。ステージ画面が動かなければ予備の回答画面に切り替える |
| 回答画面で「合言葉が違います」 | 司会者画面に出ている4桁を入れ直す（チームが変わると合言葉も変わる） |
| 観客ページが進まない | ページを再読み込みする（途中からでも追いつく） |
| 「次へ」が押せない | 回答受付中は回答が届くまで押せない。代理入力で入れる |

## 終わったら

- `スズリーグ.app` をもう一度開き、「終了する」を押す（ターミナル版なら窓で `quit` と打つ）。次に起動するときは「最初から」を選ぶ
- スマホの司会者画面の「ランキングをリセット」でデモのデータを消す
