## Scratch担当：ステージ画面を作り直して配っていること

```text
お疲れさまです。ステージ画面のことで共有とお願いです。

10/13 のデモ会のあとから、本番で開くのは Scratch のプロジェクト（1364239598）そのものではなく、
そこから作り直した画面になりました。
・大画面用（数字キーなし）: https://suzuleague-cloud.onrender.com/stage/view/
・出演者用（数字キーあり）: https://suzuleague-cloud.onrender.com/stage/play/

絵・音・演出は作ってもらったものをそのまま使っていて、裏方PCとやり取りする「通信」スプライトの
中身だけをこちらで入れ替えています。そのため、次のものは Scratch 側で直さなくて大丈夫です。
・途中で開き直すと画面が崩れる件
・1問目で早く回答受付に進めると数字キーが出ない件
・全体結果の得点表（こちらで「結果発表」の画面を作って置き換えました）
・チーム名の札（決まったチーム名を書いた絵に、こちらで差し替えます）

お願いは2つです。
1. プロジェクトを直したら教えてください。こちらで作り直すまで本番の画面には出ません（コマンド1つで作り直せます）
2. メッセージや変数の名前を変えるときは、変える前に教えてください。名前で頼っているので、変わると作り直しが止まります
   （一覧: https://github.com/suzuka-kosen-festa/2026-suzuleague/blob/main/docs/protocol.md#元のプロジェクトに頼っていることscratch担当へ ）

10/13 に直してもらった分（エキシビションモードの表示など）は、10/14 に取り込んで本番に出しました。
そのときに1つ気づいたことがあります。スプライト「UI」の「クローンされたとき」で、待機画面（役割＝8）のすぐ下に足した
「もし 役割＝8 なら … コスチュームを エキシビションモード にする」は、役割＝9 のつもりではないでしょうか。
いまは表示されていますが、UI の絵や位置を変えて保存すると、別の絵や位置で出てしまいます。

作り直しのときにこちらで補ったところの一覧も置いておきます。プロジェクト側でも直しておくと、
TurboWarp で直接開いたときも同じ動きになります（直さなくても本番には影響しません）。
https://github.com/suzuka-kosen-festa/2026-suzuleague/blob/main/docs/scratch/README.md
```

## イベント担当：電子黒板の音と回線

壇上の電子黒板に、スタッフの Windows PC で配信用の画面を映すことになった（10/21 に確認）。残りを聞く文面。

```text
お疲れさまです。電子黒板には、スタッフの Windows PC で映す予定と聞きました。ありがとうございます。
リハーサルの前に、残りの2つを教えてもらえると助かります。

1. 音はどこから出しますか？ 電子黒板のPCと出演者の iPad の両方でステージ画面を開くので、
   両方から音を出すと二重になります。どちらか片方を消音にしたいです（電子黒板側から出すのがおすすめです）
2. 電子黒板のPCの回線（会場のWi-Fiかテザリングか）

電子黒板のPCでは、Chrome か Edge で https://suzuleague-cloud.onrender.com/stage/view/ を開いて1回クリックし、
右上のボタンで全画面にします。スリープは切っておいてください。
```

## イベント担当：チーム名と登場順

```text
お疲れさまです。チーム名と登場順が決まったら教えてください（企画書の「参加者から確認すること」の件です）。

チーム名は、司会のスマホ・観客のスマホの結果画面に加えて、大画面のチームの札と結果発表にも出るようになりました。
・10文字くらいまでだと、どの画面でも見やすいです（長い名前も小さくして表示はできます）
・登場順と、各チームのメンバー（回答する順）もあわせてもらえると、こちらの設定を一度で済ませられます
  （メンバーの名前は画面には出しません）

決まってからこちらの設定は数分で終わるので、直前でも間に合います。できればリハーサルまでにお願いします。
```

## イベント担当：問題表の直し・アンケートの締め切り・司会への伝言

```text
お疲れさまです。問題と司会のことで3点お願いです（以前お伝えした内容と同じです。済んでいたらすみません）。

1. 問題表（スプレッドシート「スズリーグ　問題」）の直し
   システムのほうは正しい値で動いていますが、司会が問題表を読み上げるので、表のほうもそろえておきたいです。
   ・チーム2・1問目: 「同行会」→「同好会」
   ・チーム2・2問目: 「竹重求先生」→「竹茂求先生」（アンケートの設問の表記）
   ・チーム4・3問目（コンソメ）: 答え 37 → 38（元データ 186/487人 = 38.2%）

2. アンケートのフォームを閉じてください
   回答が増えると答えが変わりうる問題があります（「内申点45」は26.5%前後で、四捨五入の境目です）。

3. 司会への伝言
   ・出演者はステージの端末の数字キーで答えます。司会はスマホの司会者画面で「次へ」を押して進めます
   ・正解発表のあと15秒は「次へ」が押せません（大画面の演出が終わるのを待つため。画面に残り秒数が出ます）
   ・「次へ」は続けて押さないでください（1秒以内の2回目は取り消されます）
   ・ステージの端末が使えなくなったときだけ、出演者にスマホの予備の回答画面で答えてもらいます。
     そのときは司会者画面に出る4桁の合言葉を出演者に伝えてください
```

## イベント担当：リハーサルと裏方PC

リハーサルは今週中と決まった（10/19 に確認）。細かい日時と、当日の体制を聞く文面。

```text
お疲れさまです。リハーサルは今週と聞きました。システムのほうも、それに合わせて準備します。
次の4つを教えてください。

1. リハーサルの日時と場所（会場のWi-Fiと電子黒板は会場でしか確かめられないので、会場で通したいです）
2. 当日、裏方PCの番をする人（アプリを開いて見ているだけで、コマンドの知識はいりません。止まったときは開き直すだけです）
3. 裏方PCの置き場所と回線（会場のWi-Fiかテザリングか。止まると全員の画面が止まるので、安定した回線がいいです）
4. 出演者の iPad を誰が用意するか（スリープと自動ロックを切っておけるもの）
```
